#  Viajes Aventura - Sistema de Gestión Turística

¡Bienvenido al repositorio oficial del sistema de software de **Viajes Aventura**! 

Este proyecto consiste en una aplicación desarrollada en **Python** bajo el enfoque de **Programación Orientada a Objetos Seguro (POOS)**. Su objetivo principal es modernizar y automatizar la operación diaria de nuestra agencia de viajes, dejando atrás los registros manuales para dar paso a una plataforma segura, organizada y confiable.

---

## ¿De qué trata este proyecto?

**Viajes Aventura** es una empresa dedicada a la planificación y venta de experiencias turísticas. Ante la necesidad de escalar sus operaciones de forma ordenada y proteger la información de sus clientes, nace esta solución de software que centraliza:

1. **Destinos Turísticos:** Control total sobre los lugares disponibles para viajar (creación, edición, listado y eliminación).
2. **Paquetes Turísticos:** Armado de paquetes personalizados combinando múltiples destinos, fechas y cálculo automático de costos.
3. **Reservas de Clientes:** Registro y seguimiento del historial de reservas realizadas por los usuarios.
4. **Seguridad y Protección de Datos:** Acceso mediante autenticación de usuarios, validación de datos y resguardo seguro de credenciales en base de datos.

## Tecnologías Base

* **Lenguaje:** Python 3
* **Paradigma:** Programación Orientada a Objetos (POO)
* **Almacenamiento:** Base de datos relacional (Persistencia de datos)
* **Seguridad:** Librerías oficiales de Python para encriptación y validación

## Puesta en Marcha Rápida

Para ejecutar el proyecto en tu entorno local, sigue estos pasos básicos:

1. **Descarga o clona este repositorio:**
   ```bash
   git clone https://github.com/remi1223/Agencias_ViajeRG.JC.git
   cd viajes-aventura
   ```

2. **Instala las dependencias necesarias:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Inicia el sistema:**
   ```bash
   python main.py
   ```
